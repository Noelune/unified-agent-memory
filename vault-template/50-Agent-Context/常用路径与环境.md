# 常用路径与环境

> 常用路径、工具版本、环境事实。逐行一条。以下为 dsh-unified-agent-memory 插件配置项。

- UNIFIED_MEMORY_VAULT — path to the Obsidian vault (required; config key vaultPath)
- UNIFIED_MEMORY_PYTHON — Python interpreter for the memory core (default "python"; config key pythonPath)
- UNIFIED_MEMORY_COREPATH — path to core/ directory for PYTHONPATH (auto-set by plugin; config key corePath)
- UNIFIED_MEMORY_REMOTE_URL — optional remote index server URL
- UNIFIED_MEMORY_REMOTE_TOKEN — optional remote index auth token
